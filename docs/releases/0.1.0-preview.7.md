The seventh preview of WxKit names its acronyms and abbreviations as .NET does, and gives the flags that were `int`s enum types. These are the API changes 0.1.0 needs, which come before it so that nobody depends on the old names. Install it with `dotnet add package WxKit --prerelease`.

## What is new

- `AccessibilityInfo.Of(window)` reads a window as screen readers do, through MSAA on Windows, NSAccessibility on macOS, and ATK on Linux: its role, its name, and whether it is enabled, focused, or checked. WxKit's tests use it to check a labeled form on all three platforms, and an application's own tests can too.
- On Linux and macOS, a control is named by the label just before it, as on Windows. wxGTK gave a list box's, a multi-line text box's, or a slider's label to the widget around the one that gets the focus, so Orca read it without its label, and on macOS nothing tied a label to its control for VoiceOver.

## Changes that may need code changes

- An acronym of three letters or more is in Pascal case, as .NET writes them, rather than in upper case, as wxWidgets does. Two letters stay upper case, as `UI` and `DC` do in .NET. For example:
  - `HyperlinkCtrl.URL` is `Url`, `WebView.PrintToPDF` was already `PrintToPdf`, and `Image.SetRGB` is `SetRgb`.
  - `Window.FromDIP` and `ToDIP` are `FromDip` and `ToDip`, `DPIChangedEvent` is `DpiChangedEvent`, and `GetPPIScreen` is `GetPpiScreen`.
  - The platform prefixes are `Msw`, `Osx`, and `Gtk`, as in `NotificationMessage.MswUseToasts`.
  - The styled text control's `EOL` members are `Eol`, as in `EolMode`, and `STCFocus` is `StcFocus`.
- Abbreviations are spelled out, as .NET's naming guidelines ask:
  - `Slider.SelStart`, `SelEnd`, and `ClearSel` are `SelectionStart`, `SelectionEnd`, and `ClearSelection`.
  - `ToolBar.GetToolByPos`, `DeleteToolByPos`, and `GetToolPos` end in `Position`, and so do `Window.GetScrollPosition` and `SetScrollPosition`.
  - `FlexGridSizer`'s `Col` members are `Column`, as in `AddGrowableColumn`, and `ColWidths` is `ColumnWidths`.
  - `Window.UseBgCol()` is the property `UsesBackgroundColor`, `CalendarCtrl.ResetAttr` is `ResetAttributes`, `Font.NativeFontInfoDesc` and `NativeFontInfoUserDesc` end in `Description`, and `Image.ImageExtWildcard` is `ImageExtensionWildcard`.
  - Event types spell out `Selection`, `Column`, and `Position`, as in `EventType.TreeSelectionChanged` and `ListColumnClick`. The controls' events had full names already.
  - The styled text control keeps Scintilla's names, which its documentation uses.
- Flags and modes that were `int`s are enums: `DC.BackgroundMode` is a `BrushStyle`, `DataViewEvent.DragFlags` a `DragFlags`, `StatusBar.GetStatusStyle` a `StatusBarFieldStyle`, `WebView.Print`'s flags `WebViewPrintFlags`, and `ArtProvider.GetMessageBoxIcon`'s a `MessageDialogStyle`. `SplitterWindow.SplitMode` can be set, and `DC.AreAutomaticBoundingBoxUpdatesEnabled` is a property.
- `CheckBox`, `RadioButton`, and `ToggleButton` say whether they are checked with `IsChecked`, which can be set, as WPF's do, rather than with `Value`. `CheckBox` had both, with `IsChecked` read-only.
- A control's events don't repeat its name: `ListCtrl.ListItemSelected` is `ItemSelected`, `ListColClick` is `ColumnClick`, `TreeCtrl.TreeSelChanged` is `SelectionChanged`, `TreeItemGettooltip` is `ItemToolTipRequested`, and `DataViewCtrl.DataViewItemActivated` is `ItemActivated`. `ToolBar.Tool` is `ToolClicked`, `ToolRclicked` is `ToolRightClicked`, `ToolEnter` is `ToolHovered`, `ComboBox.Text` is `TextChanged`, `Dialog.InitDialogEvent` is `Initializing`, and `FindReplaceDialog.FindClose` is `FindClosed`.
- The overloads that gave two numbers through `out` parameters, where another gives them as a `Point` or a `Size`, are gone: `Window.GetSize(out int width, out int height)` and the rest, as on `DC`, `ScrolledWindow`, and the key and mouse events. Use `Size`, `Position`, `ClientSize`, and the overloads that return one value.

The API will change before 1.0.

WxKit is heavily vibe coded. If AI-written code is a dealbreaker for you, this is not the project for you.
