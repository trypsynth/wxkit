WxKit 0.2.0-preview.2 is the second preview of 0.2.0, which changes the API where 0.1 got it wrong, as [the first preview's notes](0.2.0-preview.1.md) list. Install it with `dotnet add package WxKit --prerelease`.

## Added

- `Bitmap.NativeHandle` and `Icon.NativeHandle` give a bitmap's and an icon's own handles, an HBITMAP and an HICON on Windows, for a native API such as `Shell_NotifyIcon`, without copying the pixels into an image of its own. On macOS, a bitmap's is the CGContextRef its pixels are in, and on Linux a GdkPixbuf*, and an icon's is its bitmap's.
