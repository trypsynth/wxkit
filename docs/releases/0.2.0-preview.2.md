WxKit 0.2.0-preview.2 is the second preview of 0.2.0. Install it with `dotnet add package WxKit --prerelease`.

## Changes that need code changes

- `Translations.GetBestTranslation` counts English, which the strings are in, as a language there is a catalog for, as `AddCatalog` does. For a user who prefers English to the languages there are catalogs for, it's `en`, the language the text is in, whatever English they prefer, such as en-US. It named the next language the user prefers, so an application that took its direction from it laid out right to left in English when Hebrew came next.

## Added

- `Translations.Use` takes the assembly the catalogs are embedded in, as in `Translations.Use(typeof(MainFrame).Assembly, "MyApp")`, for a library that embeds catalogs of its own, or an application's tests, whose entry assembly is the test host. wxWidgets' own catalogs, which translate stock labels such as Cancel, are still read from the entry assembly, since the build embeds them only in an application. It read only the entry assembly's.
