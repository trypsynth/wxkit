WxKit 0.2.0-preview.2 is the second preview of 0.2.0. Install it with `dotnet add package WxKit --prerelease`.

## Changes that need code changes

- `Translations.GetBestTranslation` counts English, which the strings are in, as a language there is a catalog for, as `AddCatalog` does. For a user who prefers English to the languages there are catalogs for, it's `en`, the language the text is in. It named the next language the user prefers, so an application that took its direction from it laid out right to left in English when Hebrew came next.
