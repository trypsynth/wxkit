WxKit 0.1.0 is the first release that isn't a preview. Its API has had its pass for names and types that aren't .NET's, and from here, 0.1.x releases only fix bugs and add what needs no code changes. A change that needs code changes waits for 0.2.0. Install it with `dotnet add package WxKit`, or `dotnet add package WxKit.FSharp` for F#, or start with `dotnet new install WxKit.Templates` and `dotnet new wxkit -n MyApp`.

The seven previews' notes describe what 0.1.0 has. This release adds the last of the API pass to preview.7.

## What is new

- `TextCtrl`, `ComboBox`, and `SearchCtrl` have `SelectionStart` and `SelectionLength`, as WinForms' text boxes do.

## Changes that may need code changes

- A member that fills a list returns it, and a getter of one is a property: `ListBox.GetSelections(out int[] selections)` is `Selections`, `CheckListBox.GetCheckedItems` is `CheckedItems`, `TreeCtrl.GetSelections` is `Selections`, and `DC.GetPartialTextExtents(text)` returns the widths. `DataViewCtrl.Selections` can be set, in place of `SetSelections`.
- A getter that fills a width and a height returns a `Size`: `Printout.GetPageSizeMM(out int w, out int h)` is `PageSizeMM`, and so are `PageSizePixels`, `PpiPrinter`, and `PpiScreen`, and `ScrolledWindow.GetScrollPixelsPerUnit` is `ScrollPixelsPerUnit`.
- The overloads that duplicated a `Point` or `Rect` one are gone: `ScrolledWindow.CalcScrolledPosition(x, y, out xx, out yy)` and `CalcUnscrolledPosition`'s, which take and return a `Point`, and `DC.GetClippingBox`'s four ints.
- A getter that can fail is named as .NET's Try methods are: `ListCtrl.TryGetItemRect` and `TryGetSubItemRect`, `TreeCtrl.TryGetBoundingRect`, `StatusBar.TryGetFieldRect`, and `DC.TryGetClippingBox`.
- `TimePickerCtrl.GetTime` is gone, since `Value` gives the time.
- More abbreviations are spelled out: `Window.PrevSibling` is `PreviousSibling`, `TreeCtrl.GetPrevSibling` and `GetPrevVisible` are `GetPreviousSibling` and `GetPreviousVisible`, `KeyCode.MediaPrevTrack` is `MediaPreviousTrack`, `DirMustExist` is `DirectoryMustExist`, `ChangeDir` is `ChangeDirectory`, `GenericDirCtrlStyle.DirOnly` is `DirectoryOnly`, `FontPickerCtrlStyle.FontDescAsLabel` is `FontDescriptionAsLabel`, `ArtId.GoDirUp` and `NewDir` are `GoDirectoryUp` and `NewDirectory`, and the accessible state `ExtSelectable` is `ExtendedSelectable`. The styled text control's `SearchPrev` and `FoldLevelPrev` end in `Previous`.
- `EventType.DirCtrlFileActivated` and `DirCtrlSelectionChanged` are `GenericDirCtrlFileActivated` and `GenericDirCtrlSelectionChanged`, after their class.

## Still to come

- A grid that screen readers can read, in a 0.1.x release.
- AUI, the property grid, and rich text, which draw their own controls, until screen readers can read them.

WxKit is heavily vibe coded. If AI-written code is a dealbreaker for you, this is not the project for you.
